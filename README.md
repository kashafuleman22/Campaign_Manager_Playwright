Campaign Manager V2.0 - Playwright Automation
Project Overview
This project contains end-to-end automation tests for Campaign Manager using Playwright.

Tech Stack
Playwright
JavaScript (Node.js)
Setup Instructions
Clone the repository: git clone https://github.com/kashafuleman22/Campaign_Manager_Playwright.git

Install dependencies: npm install

Run Tests
npx playwright test

View HTML Report
npx playwright show-report
